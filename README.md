# 进销存系统（试用版）

手机优先的网页版进销存系统，单文件自包含，浏览器打开即用。适合小店老板、店员日常开单、管库存、记账。

## 在线试用

开启 GitHub Pages 后访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 功能

- **首页看板**：今日销售 / 今日毛利 / 今日单数，库存总量（进价 / 售价），客户欠款、供应商欠款，待办欠款提醒，快捷操作（可长按排序、隐藏）
- **销售开单**：单据日期（自动取当前时间）、业务员、客户、销售类型（默认批发）；两级分类选商品；扫码输入；选商品弹层支持单位（如 1 箱 = 12 瓶）、数量、单价、折扣率、折后单价、备注；出单后自动记住该客户单价
- **拆零库存（组合拆分）**：商品可设整箱 + 散瓶两种形态，各形态独立条码；卖散瓶优先扣散瓶，不够自动拆箱补上；进货 / 退货 / 盘点按单位分别入账；库存显示如「18箱 + 5瓶」
- **进货**：分类选择、行内单位下拉、按单位入库
- **销售退货**：冲回库存并生成退货款
- **盘点**：实盘整箱 / 实盘散件分别录入，自动记录盘盈盘亏
- **库存查询**：分类查看、全部 / 预警 / 无货筛选、禁售商品、预警上 / 下限
- **商品管理**：分类（含延续分类）、多单位换算（1 主 = N 副，可互换）、独立条码、进货 / 批发 / 零售价、提成金额、预警、销售状态（可禁用）、批量修改（按分类改提成 / 改价 / 禁用）、图片、备注
- **客户 / 供应商**：欠款明细、月查询（默认全部）、客户欠款提醒（按月或按单）、收款单（选客户显示应收欠款与未结单数、手动 / 自动核销、收款账户、实收、优惠）
- **财务**：收支流水、应收应付、利润
- **经营分析**：日期下拉（默认全部）、月度总销售 / 毛利 / 单数、主分类排行（前三名红 / 橙 / 绿配色）、点分类看该分类商品销售与毛利排行
- **业务员**：按商品提成金额 × 销量汇总
- **设置**：店铺名、币种符号（可自由编辑）、中英双语切换、结算账号、商品分类、计量单位、重置 / 清空数据

## 试用说明

- 数据保存在**浏览器本地（localStorage）**，换设备、换浏览器数据不互通；正式版将接入云端多账号同步
- 扫码为**手动输入条码**模式；打印导出（销售单 A4 / 小票 / 标签 / PDF / 图片）为正式版功能
- 想重置演示数据：设置页 → 清空数据 / 恢复示例数据
- 建议手机浏览器访问，桌面浏览器也可用

## 上传到 GitHub 的步骤

1. 在 GitHub 新建仓库（如 `jxc-trial`，Public）
2. 上传本目录中的 `index.html` 和 `README.md`（网页端：Add file → Upload files；或命令行 git push）
3. 打开仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，分支选 `main`，目录 `/ (root)`，Save
4. 等 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可试用

命令行方式（已装 Git 时）：

```bash
git init
git add index.html README.md
git commit -m "进销存系统试用版"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```
